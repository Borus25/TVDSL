# Практика 5. AST и таблицы символов

> Занятие 5, неделя 5, после L05. Начало HW3; завершение AST для HW2.
> P-код — идентификатор материала, не номер недели. [Календарь](README.md).

## Цели

- Построить и нормализовать AST для языка Funny.
- Организовать таблицы символов с областями видимости.
- Подготовить базовые проверки имен к HW3/проекту.

## План занятия (90 минут = 2x45 + перерыв 5)

- Блок 1 (0:00-0:45): извлечение AST из парсера; договоренности по типам узлов и структуре (операторы, выражения,
  объявления, блоки); таблицы символов: стек областей, тени имен.
- Перерыв (0:45-0:50).
- Блок 2 (0:50-1:35): базовые проверки имен (объявление до использования, повторные объявления), формат диагностики с
  позициями; небольшие тесты и контрольный перечень готовности.

## Материалы/инструменты

- Парсер (LL/LR) с выходом дерева.
- Лексер с позициями токенов.
- Набор программ на Funny с вложенными блоками/функциями, конфликтами имен.

## Упражнения (аудитория)

- Определить словарь типов узлов AST, зафиксировать поля (дети, позиция, тип узла).
- Реализовать таблицу символов: push/pop областей, поиск с учетом вложенности.
- Добавить проверки: повторное объявление в одной области, использование неизвестного идентификатора.
- Привязать ошибки к строке/столбцу (из лексера) и к узлу AST.
- Прогнать тесты: корректная программа, повторное объявление, неизвестное имя, вложенные блоки с тенями.

## Дополнительные упражнения и примеры

- Разобрать тени имен: глобальная функция `f`, локальная переменная `f` в блоке — что разрешено/запрещено?
- Формализовать AST для обессахаривания `a[i] = v` (доп. узел обновления массива) и многозначного присваивания.
- Добавить поддержку forward-decl (если нужно): функция объявлена ниже — как хранить сигнатуры?
- Сериализация AST: сделать человекочитаемый dump и сравнить с эталоном (snapshot-тест).
- Ошибки: отсутствует `returns` переменная, повторное имя параметра/возврата/локальной — сформировать диагностические сообщения.

## Примеры

- Валидный: `function sum(a:int[], n:int) returns r:int { r = a[0]; { var i:int; i = 1; } }` — показать области видимости.
- Невалидный: дважды объявлена локальная переменная в одном блоке; использование `x` без объявления.
