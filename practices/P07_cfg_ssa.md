# Практика 7. CFG, SSA и локальные оптимизации/регистры

> Занятие 7, неделя 7, после L07. Начало HW4; сдача HW4 и T1 в конце недели 8.
> P-код — идентификатор материала, не номер недели. [Календарь](README.md).

## Цели

- Построить CFG и базовые блоки из AST/IR.
- Понять живость/достижимость и подготовить точки для SSA.
- Применить локальные оптимизации (константы, CSE, DCE).
- Построить граф конфликтов и выполнить простую раскраску регистров.
- Подготовить промежуточное представление к оптимизациям и порождению кода (HW4).

## План занятия (90 минут = 2x45 + перерыв 5)

- Блок 1 (0:00-0:45): разбиение на базовые блоки; построение CFG по управляющим конструкциям/вызовам; достижимость и
  обратные ребра, интуитивно про доминаторы; живость и места phi.
- Перерыв (0:45-0:50).
- Блок 2 (0:50-1:35): локальные оптимизации (константы, упрощения, CSE, DCE) в пределах блока; граф взаимодействия и
жадная раскраска; оценка эффекта на IR.

## Материалы/инструменты

- Промежуточное представление (трехадресный код или эквивалент) из парсера/AST.
- Простые программы с ветвлениями/циклами для проверки CFG.
- Набор программ с повторяющимися выражениями и мертвыми переменными.
- Инструмент для визуализации (graphviz) или текстовые дампы/граф конфликтов.

## Упражнения (аудитория)

- Сгенерировать базовые блоки для 2-3 программ; убедиться, что вход/выход корректны.
- Построить CFG: добавить ребра для `if/else`, `while/for`, `return`.
- Отметить достижимость блоков; удалить недостижимые (опционально).
- Посчитать живость на ребрах, наметить места возможных phi (без полного SSA-алгоритма).
- В одном блоке применить константы/алгебраику, локальный DCE и CSE.
- Построить граф конфликтов по живости, раскрасить его жадно и обсудить возможные spill.
- Сохранить CFG в формате для следующих практик (json/dot/текст).

## Дополнительные упражнения и примеры

- Циклы: выделить back-edges и естественные циклы, отметить заголовки (loop headers).
- Различить fallthrough/branch: нарисовать CFG для `if/else if/else` и `while` с `break/continue` (если реализуете).
- Живость: вычислить IN/OUT множеств на ребрах для переменных из примеров; показать, где понадобится phi в SSA.
- Оптимизация перед SSA: удаление недостижимых блоков, слияние пустых блоков с единственным successor.
- Константы и DCE. Пример:

  ```ts
      t1 = 1;
      t2 = t1 + 0;
      if cond goto L1;
      t3 = t2;
  L1: return t2;
  ```

  \- что можно убрать?
- Локальный CSE: выявить повтор `a * b` или `a + b` внутри одного блока, не ломая семантику.
- Граф конфликтов: показать раскраску при 2-3 регистрах и где случается spill.
- Формат обмена: договориться о JSON/dot представлении CFG и номерах блоков для автотестов.

## Примеры

- CFG: `while (i < n) { if (a[i] > 0) r = r + a[i]; i = i + 1; }` - построить CFG, отметить живость `i,n,a,r`.
- CSE/DCE: `t1 = a + b; t2 = a + b; r = t1 + t2;` после CSE одно вычисление `a+b`, затем DCE убирает `t2`.
- Пограничный: недостижимый код после `return` - показать удаление/предупреждение.
