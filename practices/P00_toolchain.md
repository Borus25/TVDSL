# Практикум P00. Окружение и конвейер компилятора

> Занятие 1, неделя 1, после L01. Календарь: [README](README.md).

## Цели

- Подготовить воспроизводимый запуск учебного проекта из командной строки (command-line interface, CLI).
- Сопоставить входы, выходы и ошибки этапов компилятора (compiler pipeline).
- Научиться фиксировать ожидаемый результат теста до реализации этапа.

## Материалы

- Спецификация [Funny](../funny.ru.md) и требования [проекта](../project/project_spec.md).
- Установленные инструменты выбранного языка; для JVM — JDK.
- Небольшая программа и подготовленные преподавателем результаты её обработки: токены, дерево, целевой код.
  Если демонстрационного компилятора нет, используются эти результаты как раздатка.

## План занятия (90 минут работы + перерыв 5 минут)

- 0:00–0:20: проверить версии инструментов, собрать и запустить минимальную программу из CLI.
- 0:20–0:45: сопоставить исходный текст, поток токенов, дерево и результат исполнения по раздатке.
- 0:45–0:50: перерыв.
- 0:50–1:15: классифицировать ошибки по этапам, подготовить позитивные и негативные входы.
- 1:15–1:35: оформить команды запуска, ожидаемые результаты и границы первого прототипа проекта.

## Упражнения

1. Зафиксировать версии инструментов и команды сборки/запуска в README своего проекта.
2. Для входа `x` `=` `1` `+` `2` `;` сопоставить символы с готовым списком токенов из раздатки.
3. Указать этап обнаружения неизвестного символа, пропущенной скобки и неизвестного имени.
4. Подготовить три тестовых входа и объяснить ожидаемый результат каждого словами.
5. Обозначить интерфейсы будущих этапов: что каждый принимает и возвращает.

## Результат

- Минимальная программа запускается по записанной команде.
- Есть таблица «вход → ожидаемый результат → этап обнаружения ошибки».
- Есть схема этапов проекта и список вопросов к спецификации.
