## Дополнительные упражнения и примеры

- Обессахаривание `a[i]=v`: убедиться, что тип обновляемого выражения — `int[]`, индекс — `int`, RHS — `int`.
- Множественные возвраты: присваивание кортежа в список переменных, ошибки несоответствия длины.
- Рекурсивные функции: проверка сигнатуры до тела (фиксировать тип в таблице символов, затем проверять тело).
- Опциональный вывод типов локальных: первый корректный assignment задаёт тип; конфликтующие присваивания → ошибка.
- Негатив: попытка записи в параметр, смешение `int` и `int[]` в выражении, неверное число аргументов/результатов.

## Примеры

- Валидный: `function inc(x:int) returns r:int { r = x + 1; }`
- Невалидный: `function bad(a:int[]) returns r:int { a = a; }` (запись в параметр) / `r = a + 1;` (несовместимость типов).
- Пример с опциональным выводом: `uses tmp; tmp = 1; tmp = tmp + 2;` → тип `int`; `tmp = [1]; tmp = 2;` → ошибка.
