# Практика 4. LR/SLR: таблицы сдвиг/свертка

> Занятие 4, неделя 4, после L04. Ветка LR; альтернатива — P03. Начало HW2.
> P-код — идентификатор материала, не номер недели. [Календарь](README.md).

## Цели

- Освоить построение LR(0)/SLR таблиц.
- Понять и устранить конфликты shift/reduce, reduce/reduce.
- Сравнить поведение LR-генератора с демонстрацией LL-ветки преподавателем.

## План занятия (90 минут = 2x45 + перерыв 5)

P03 и P04 — две ветки одного занятия. Каждый студент выполняет одну ветку для HW2.
Преподаватель предоставляет каркас парсера и небольшую грамматику выражений для каждой ветки.

- 0:00–0:15: общая демонстрация LL и LR на одной последовательности токенов.
- 0:15–0:45: работа в выбранной ветке: замыкание одного LR(0)-состояния, ключевые клетки готовой SLR-таблицы и один конфликт.
- 0:45–0:50: перерыв.
- 0:50–1:20: заполнение каркаса выбранного парсера, подключение лексера P02, запуск тестов.
- 1:20–1:35: сравнение подходов по раздатке преподавателя, разбор одной ошибки, план HW2.

Обязательный минимум: разбор одной подграмматики выражений, один положительный и один отрицательный тест.
Упражнения ниже — банк для выбранной ветки и самостоятельного доведения HW2, а не два полных практикума за занятие.
Реализация обеих веток не требуется. Полный AST завершается после L05/P05 к сдаче HW2 на неделе 5.

## Материалы/инструменты

- Часть грамматики (выражения, присваивания) для построения вручную.
- Генератор LR (bison/yacc или аналог).
- Лексер из P02, использующий результаты HW1.
- Примеры с конфликтами (dangling else, приоритеты операций).

## Упражнения (аудитория)

- Построить LR(0) автомат для выбранных правил, получить множества состояний.
- Составить ACTION/GOTO, отметить конфликты shift/reduce и reduce/reduce.
- Перейти к SLR(1): ограничить редукции FOLLOW-множествами, проверить исчезновение конфликтов.
- В генераторе: задать приоритеты/ассоциативность операторов, убедиться в отсутствии лишних shift/reduce.
- Прогнать 2-3 позитивных и 2-3 негативных теста, сравнить сообщения об ошибках с LL-парсером.

## Дополнительные упражнения и примеры

- Dangling else: показать, почему LR устраняет неоднозначность иначе, чем LL; задать правило приоритетов в bison/yacc.
- Конфликты для выражений: без приоритетов `+`/`*` → shift/reduce; ввести `%left '+' '-'` / `%left '*' '/'` и пересобрать таблицу.
- Ручной SLR: возьмите подграмматику выражений Funny (с обессахариванием `a[i]=v`) и покажите, какие редукции остаются конфликтными.
- Ошибки: добавить правила `error` в bison/yacc для восстановления (аналог режима паники LL) и сравнить поведение.
- Сравнение LL vs LR: одна и та же программа с ошибкой — какая ветка даёт более информативный диагноз?

## Примеры

- Валидный: `function f(x) returns r { r = x + 2 * 3; }` → таблицы без конфликтов после задания приоритетов.
- Невалидный: `function f(x returns r { r = x + ; }` (пропущена скобка/закрывающая) → убедиться, что LR-парсер не зацикливается.
- Пример грамматики для построения LR(0) вручную:  
  `S'→S; S→E; E→E+T|T; T→T*F|F; F→(E)|id`
