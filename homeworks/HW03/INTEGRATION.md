# Что именно переиспользовано из HW2

Исходный репозиторий: https://github.com/Borus25/TVDSL/tree/HW01/homeworks/HW02

Ветка: `HW01`. Зафиксированный коммит: `30a7a68fbb3d3256ae44042742850ab405602f77`.

Задание: https://github.com/Borus25/TVDSL/blob/HW01/homeworks/HW03/HW03_types.md

При разработке также учтена приложенная лекция «Семантический анализ: таблицы символов и проверка типов»: два прохода, структурная унификация, bool-условия, области видимости, аннотированный AST, диагностические позиции и подавление каскадов.

| Файл | Изменения |
|---|---|
| `lexer.py` | Байтово совпадает с HW2, включая позиции токенов, peek, recovery и обработку комментариев |
| `dfa_build.py` | Байтово совпадает с HW2 |
| `ll1.py` | Байтово совпадает с HW2; анализирует новую grammar.txt |
| `funny_ast.py` | Сохранены все старые классы; добавлены keyword-only type, VarDecl, аннотации сигнатуры и позиции; расширены сериализация и S-expression |
| `parser.py` | Сохранён рекурсивный спуск и panic recovery; добавлены type, var, аннотации, вложенные индексы и индексация результата вызова |
| `funny.lex` | Добавлены VAR/TYPE_INT/TYPE_BOOL/TYPE_ARRAY и ':' |
| `dfa.json` | Пересобрана существующим dfa_build.py |
| `grammar.txt` | Обновлена грамматика под расширенный парсер; 0 LL(1)-конфликтов |
| `main.py` | Новый CLI над существующим parse и новым семантическим проходом |
| `funny_types.py`, `semantic.py` | Новые модули HW3 |

Формат Function.params по-прежнему `list[str]`, Function.returns — имя результата. Позиционные конструкторы старых узлов сохранены, поле type keyword-only. Старый нетипизированный синтаксис можно разбирать с `--parse-only`; при семантической проверке требуются новые явные аннотации сигнатур. Слова `var/int/bool/array` стали зарезервированными: это намеренное расширение языка.

Копия HW02 в архиве не является заменой вашего кода и не изменялась. `run_all_tests.py` запускает HW02 и HW03 в отдельных процессах, чтобы одноимённые модули parser/lexer/funny_ast не смешивались в sys.modules.

`generated/provenance.json` содержит SHA-256 исходных Python-файлов HW2. `generated/changes_from_hw2.diff` показывает локальные изменения унаследованных исходников; новые модули входят в архив как отдельные файлы. Коммиты и push в GitHub не выполнялись.
