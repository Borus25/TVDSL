# Краткий план демонстрации HW5

## 1. Модель и допущения

Открыть models/original.smv: четыре состояния, начало s0, переходы P09, нет FAIRNESS. Сказать: «Система безопасна относительно error, но бесконечное ожидание ответа разрешено».

## 2. Свойства

Открыть SPECIFICATIONS.md и показать шесть формул: три safety, две liveness, диагностическую EF error. Объяснить: false у EF error в fixed — желаемое отсутствие пути, не ошибка запуска.

## 3. Реальный NuSMV-прогон — обязателен для завершения инструментального пункта

```bash
python3 run_nusmv.py --binary /path/to/NuSMV
```

Показать generated/nusmv/results.json и сырые stdout-логи original/p04_response, fixed/p04_response, error_transition/p01_no_error. Если инструмент ещё не установлен, не утверждать, что проверка прошла. В выданном архиве честно стоит not_run.

## 4. Минимальный контрпример и исправление

```bash
python3 main.py build
```

Открыть generated/original.log: префикс s0→s1 и цикл s1→s1. Открыть models/fixed.smv: удалена только самопетля s1→s1. В generated/fixed.log живость истинна.

Объяснить: конечного ожидания недостаточно для нарушения F ack; нужен бесконечный путь без ответа.

## 5. Экзистенциальная CTL

Открыть generated/original.json: EF error={s3}, достижимые={s0,s1,s2}. Это обоснование отсутствия пути. В error_transition показать положительное свидетельство s0→s1→s3.

## 6. Связь с вашим HW4

```bash
python3 main.py export-hw4 examples/hw4_loop_sum.ir.json --out generated/hw4_cfg
```

Показать четыре блока, CFG/SMV и analysis.json. Сказать: «Использована моя функция cfg() из HW4. Но здесь стёрты условия, так что бесконечный путь в абстракции может быть невозможен при реальных значениях i и n».

Для загрузки именно установленного HW4:

```bash
python3 run_tests.py --hw4-dir ../HW04
```

## 7. Тесты и границы

```bash
python3 run_tests.py
```

Показать 35 тестов и отдельный статус внешнего инструмента. Не путать живость протокола «когда-нибудь будет ответ» с liveness переменных из HW4 «значение ещё будет прочитано».

Завершить: «Безопасность не гарантирует прогресс. В исходном графе ошибок нет, но ответ может откладываться бесконечно. Контрпример указывает на разрешённую самопетлю; после её удаления свойства живости выполняются в исправленной модели».
